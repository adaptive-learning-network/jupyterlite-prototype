# Course artwork

Course comics should portray respectful professional collaboration. Give people clearly separate work positions and visible personal space. Avoid bodily overlap, shoulder contact, crowding, leaning over another person, or standing immediately behind a seated colleague. Use a wider scene, shared table, or central display when needed. Apply this to all colleagues regardless of gender.

Preserve the instructional sequence, character identities, and roles. Inspect every panel after generation or editing. Keep review history and generation prompts in repository documentation rather than learner notebooks.

See the [2026-10-19 comic review](../docs/audit/comic-portrayal-review.md) for the complete 14-strip inventory, findings, and prompts used to revise Units 1–3. The raster assets are in `content/exercises/assets/`; Units 4–14 have editable SVG sources here, generated by the corresponding notebook authoring scripts.
